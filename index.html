Share the environment. Not the blast radius.

When tasks in a bundle share one serverless environment, setup time collapses, but every new pair of tasks is another chance for a dependency clash. This system finds the largest safe cap, k, and only ships it when the statistics can prove the guardrails hold.

01 / Decision

One default. Four guardrails. Five owners.

PRD: docs/PRD.md

Customer problem

The same packages, installed eight times

An 8-task bundle sets up 8 environments before any work runs. Data engineers wait; FinOps pays for idle setup minutes.

Proposed change

Shared by default, capped at k

Tasks join a shared serverless environment (from the bundle-root pyproject.toml), at most k per environment, with a dependency check at deploy time.

Success metric

Setup minutes per run, −30%

Judged on the lower 95% confidence bound, not the point estimate.

Guardrails (all must hold, judged on the pessimistic CI bound)
GuardrailStatisticThreshold
Runs hitting a dependency conflictWilson upper 95%≤ 2.0%
Hard failures needing a humanWilson upper 95%≤ 0.3%
Tasks re-run per 100 runsmean≤ 8
P90 setup delay on the critical pathvs. isolatedno worse
Stakeholders

Bundles & CLI engineering · Serverless compute · Jobs PM · Support & field engineering · Customer FinOps admins

Why it's hard

Conflict pairs grow as k(k−1)/2. Risk climbs faster than savings.

    07 / Method
    Rejection sampling, validated.
    Setup times follow a two-hump curve (cached vs. cold installs) with no simple inverse CDF.
    
  
    
    
    Proposals under the envelope M·g
    
    
    Accepted draws vs. target density
    The Python test suite also runs a Kolmogorov–Smirnov test against the exact CDF.
    
    
      
      
    1. Target. f(s) = 0.7·Gamma(2, 18 s) + 0.3·Gamma(4, 30 s). Its height is easy; sampling it directly is not.
      2. 
      
    2. Envelope. g = Exponential(mean 70 s), drawn by inverse CDF s = −μ ln(1−U). M = sup f/g, found on a fine grid plus a 1% margin.
      3. 
      
    3. Accept. Keep s when V ≤ f(s)/(M·g(s)). Kept draws follow f exactly; the keep rate is 1/M.
      4. 
      
    4. Common random numbers. The same draws replay every cap, so differences between caps are policy, not noise.
      5. 
      
    5. Uncertainty. Savings: batch-means CI over 20 batches. Rates: Wilson score intervals. Decisions use the pessimistic bound.
      6. 
      
    6. Limits. Conflicts are assumed independent across pairs; overhead constants are assumptions until beta telemetry replaces them (see sensitivity).

    08 / System
    What runs where.
    Architecture · Case study · Evaluation · Design system
    
  
    
    
    Browser
    ES-module engine in a Web Worker · Three.js shader terrain · accessible SVG charts · URL-encoded scenarios
    
    
    Persistence
    SQLite in WASM (sql.js), snapshotted to IndexedDB · same migration file as the API · read-only console in a rolled-back savepoint
